## 🚀 三步安装到 iPhone

### 第一步：上传到 GitHub

1. 注册 GitHub：https://github.com/signup
2. 创建新仓库：https://github.com/new（公开仓库即可）
3. 把 `ClickerApp` 文件夹的所有内容上传到仓库

上传方法（任选其一）：

**方法 A - Git 命令行（推荐）**
```bash
cd "D:\APP\xwechat_files\wxid_11kwi97la9kt22_36c9\msg\file\2026-05\ClickerApp"
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/仓库名.git
git push -u origin main
```

**方法 B - 手动上传**
1. 打开你的 GitHub 仓库
2. 点击 "uploading an existing file"
3. 拖入 `ClickerApp` 文件夹所有文件

### 第二步：等待构建完成

1. 前往你的仓库页面：`https://github.com/YOUR_USERNAME/仓库名/actions`
2. 点击 `build-ios` 工作流
3. 点击 "Run workflow" -> "Run workflow" 触发构建
4. 等待 15-25 分钟

### 第三步：下载并安装 IPA

1. 在 Actions 页面找到运行记录
2. 点击最右侧的 `ClickerApp` 下载 artifact（是一个 zip 文件）
3. 解压得到 `ClickerApp.ipa`

**安装 IPA 到 iPhone：**

推荐使用 **Esign**（最简单）：
1. 在安卓上搜索下载 "Esign" 签名工具
2. 打开 Esign，登录你的 Apple ID
3. 点击"签名安装"，选择刚才下载的 `ClickerApp.ipa`
4. 安装完成后，在你的 iPhone 上就能找到"连点器"图标
5. 在 iPhone 的 设置 -> 通用 -> 描述文件与设备管理中 信任你的 Apple ID

> ⚠️ 免费签名有效期 7 天，过期后需要重新用 Esign 签名安装

## ⚙️ 使用连点器

1. 打开「连点器」App
2. 在「触控板」标签页点击屏幕设置点击位置
3. 在「控制面板」设置点击频率和模式
4. 点击"开始"启动连点
5. 在「预设」标签页保存常用配置

## 💡 功能说明

| 功能 | 说明 |
|------|------|
| 持续点击 | 无限循环，手动停止 |
| 次数点击 | 设定次数后自动停止 |
| 频率调节 | 50ms ~ 5000ms |
| 随机偏移 | +/- 0-20 像素 |
| 随机间隔 | 更自然的点击节奏 |
| 触觉反馈 | 每次点击震动 |
| 预设保存 | 保存常用配置 |

## ⚠️ 注意事项

- 此连点器在 App **内部** 生效，无法控制其他 App
- 免费签名每 7 天需重新签名
- 最多绑定 3 台设备
- 所有功能正常，无限制
