# iOS 连点器 - GitHub Actions 一键构建

## 使用方法

### 1. 创建 GitHub 仓库

```bash
# 在 https://github.com/new 创建新仓库
# 然后在本地执行：

cd "D:\APP\xwechat_files\wxid_11kwi97la9kt22_36c9\msg\file\2026-05\ClickerApp"
git init
git add .
git commit -m "Add iOS clicker app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/clicker-ios.git
git push -u origin main
```

### 2. 等待自动构建

- 推送代码后，GitHub 会自动开始构建
- 前往 https://github.com/YOUR_USERNAME/clicker-ios/actions
- 点击最新的 `build-ios` 运行
- 等待 10-20 分钟

### 3. 下载 IPA 文件

- 在 Actions 页面找到 `build-ios` 运行
- 点击 `ClickerApp` Artifact
- 下载 `ClickerApp.zip` 并解压得到 `ClickerApp.ipa`

### 4. 安装到 iPhone

**推荐方案：Esign（安卓端）**
1. 下载 Esign for Android
2. 登录你的 Apple ID
3. 点击 "签名安装" -> 选择 `.ipa` 文件
4. 安装完成

**备选方案：AltStore**
1. Mac 上安装 AltStore
2. iPhone 和 Mac 同网络
3. 通过 AltStore 安装

## 注意事项

- 免费 Apple ID 签名的 App 每 7 天需重新签名
- 最多 3 台设备
- 所有功能正常
